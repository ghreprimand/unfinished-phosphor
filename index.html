Usage notes

Display controls

Presentation
Website uses larger type and stronger text glow. Dashboard uses smaller type and less glow.
Palette
Changes semantic colors only. Layout, font, density, and content remain the same.
Optical controls
Glow softness adjusts text-shadow radius and strength. Raster controls the stationary line and RGB mask; Glass controls vignette and reflection. All three accept 0–100 and are included in exported configurations. Code and input text stay sharp.
Density
Adjusts panel and table spacing without shrinking the type.
Effects
Ambient adds light that responds to the pointer. Static CRT keeps glow and glass. Off removes decorative treatment. Crisp text removes text halos independently.
