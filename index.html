Integration

Configuration

Load src/core.css and optionally src/components.css first. The website also loads src/fonts.css and uses data-ph-font="victor-mono". Then use these local modules with an existing HTML container.

Usage notes

Display settings

Presentation
Website uses larger type and stronger text glow. Dashboard uses smaller type and less glow.
Palette
Changes semantic colors only. Layout, font, density, and content remain the same.
Density
Adjusts panel and table spacing without shrinking the type.
Effects
Ambient adds light that responds to the pointer. Static CRT keeps glow and glass. Off removes decorative treatment. Crisp text removes text halos independently.

Getting started · Component reference · Full integration guide · Report an issue

Reduced motion pauses ambient rendering and retains static styling. All samples use invented data; no service is connected.
